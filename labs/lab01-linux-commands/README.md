# Lab 1: Linux Commands

**Topic:** operating system basics and the Linux commands for the quiz (Chapter 1).
**Status:** ✅ study guide ready

## What you will learn

- What an OS does, and how cooperative and preemptive multi-tasking differ
- Process vs. thread, and virtual machines (host vs. guest)
- The Linux commands for the quiz: processes, memory, storage, users, network and utilities

## Files

| File | What it is |
|------|------------|
| [lecture.md](lecture.md) | Theory, a task→command table for each topic, a cheat sheet, and a practice quiz |

There is no separate exercises file. The practice quiz is at the end of `lecture.md` (section 10).

## How to study

1. Read section 1 (theory) once.
2. Install the packages from section 0.
3. For each task table (sections 2–8), type every command yourself in a terminal.
4. Do the practice quiz without looking at the answers. Aim for about 2 minutes per task.

## Key words

OS, process, thread, time sharing, timer interrupt, job control, `nice`, pipe, file permissions, symbolic link.
See the [glossary](../../docs/glossary.md).
